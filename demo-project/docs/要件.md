# レビュー台帳

生成AIに「仕様レビューを3分で終わらせる社内画面を作って」と頼んだ成果物。実装コードは見ない。この Markdown と `preview/` の HTML だけで判断する。

## 目的

レビュー担当が、チケットの完了条件と画面を並べて確認できるようにする。

## 対象ファイル

| パス | 役割 |
| --- | --- |
| `preview/index.html` | このビューアの使い方 |
| `preview/board.html` | 今日の一覧 |
| `preview/ticket.html` | チケット詳細 |

## やらないこと

- チケットの新規作成
- 認証
- 本番API接続
